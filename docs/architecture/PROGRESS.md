## 次の操作

R1-G3bとして責務間の許可依存方向を定義する。

1. R1-G3aの9責務を節点とし、各責務が利用できる下位責務と公開接続面を設計する。
2. 現在の15ターゲット関係を責務間の辺へ射影し、許可方向に一致する辺とR1-G4で
   基準化する既存違反を分類する。
3. UI表示から文書、入出力、入力、描画への接続と、プラグイン発見機構から機能所有者への
   登録方向を明文化する。
4. 許可依存方針を機械可読にし、未知の責務、自己依存、循環、未分類の現在辺を診断する
   契約試験を追加する。
5. 全検証を成功させ、R1-G4の既存違反基準と継続検査を次の作業にする。
