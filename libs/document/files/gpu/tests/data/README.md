# GPU recovery version 1 fixture

`gpu_recovery_v1.bin` is original LibrePaint test data, generated by
`KisGpuDocumentRecoveryFile::write()` from the explicit values in
`KisGpuDocumentRecoveryFileTest::versionOneFilePreservesRecordedImages()`.
It is licensed under GPL-2.0-or-later, like its generating test.

The maintained contract includes a dense RGBA8 checkpoint, one sparse mask
with transparent RGB, shared selection and texture inputs, fractional brush
geometry and fade, opacity, coverage, texture strength, normal and erase
operations, two history frames, a Redo position, an unfinished edit, and UTF-16
code units including an unpaired surrogate and NUL. The test compares newly
written bytes with this file, then reads this fixed file on a replacement GPU
and checks the recorded head, preview, mask, and Redo image hashes.

Classification: maintained file and image contract. New format versions add
their own fixtures while retaining this version's reader and image checks.
