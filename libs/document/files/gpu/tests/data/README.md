# GPU recovery file fixtures

`gpu_recovery_v1.bin` and `gpu_recovery_v2.bin` are original LibrePaint test data,
generated by the corresponding format version of `KisGpuDocumentRecoveryFile::write()`
from the explicit values in
`KisGpuDocumentRecoveryFileTest::versionedFilesPreserveRecordedImages()`.
They are licensed under GPL-2.0-or-later, like their generating test.

The maintained contract includes a dense RGBA8 checkpoint, one sparse mask
with transparent RGB, shared selection and texture inputs, fractional brush
geometry and fade, opacity, coverage, texture strength, normal and erase
operations, two history frames, a Redo position, an unfinished edit, and UTF-16
code units including an unpaired surrogate and NUL. Version 2 also makes the
Redo layer hidden and locked. The test compares newly written version 2 bytes
with its fixture, then reads each fixed file on a replacement GPU and checks
the recorded head, preview, mask, and Redo image hashes and layer state.
Version 1 layers restore as visible and unlocked.

Classification: maintained file and image contract. New format versions add
their own fixtures while retaining this version's reader and image checks.
