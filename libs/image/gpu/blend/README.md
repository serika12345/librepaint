# Finite RGBA8 channel values

`rgba8-nonlinear.bin` supplies exact channel results for the 28 separable blend
operations listed in `rgba8-nonlinear.json`. GPU painting and projection read the
values from a `RGBA8Uint` texture array. Sparse group defaults read the same
immutable resource. Partial alpha, selection coverage, canvas opacity and channel
protection use the shared integer compositor after the channel lookup.

The resource contains all 256 source and 256 destination values. Four modes share
one texture layer: `x = destination`, `y = source`, `layer = mode / 4`,
`component = mode % 4`. The seven layers occupy 1,835,008 bytes. A renderer uploads
them once when a requesting paint operation or projection first needs them; the
allocation counts against its resident-byte limit. The renderer retains the
immutable texture for its lifetime. Ordinary rendering binds a single zero
placeholder until the full resource is needed.

The manifest records the producing revision, algorithm inputs, adopted license,
mode order and resource hash. The producer evaluates the existing native channel
functions, including their binary32 input normalization and final byte rounding.
This finite representation preserves those results across GPU math libraries.

From a configured native test environment, build the CPU reference's pigment
library and regenerate with:

```sh
./scripts/run-shared-test-env ./scripts/gpu/generate-rgba8-blend-tables
```

`--reference-root` selects the checkout providing the reference algorithms;
`--build-dir` selects its configured native build. The reference revision and
source hashes accompany the generated values. `--output` selects the artifact
directory. A synchronized verification checkout supplies its source revision
with `--source-revision`.

Review regenerated byte differences with their source changes. The public
`TestDocument::testQuantizedBlendMatchesEveryRgb8Pair` contract compares every
channel pair with the native compositor. The edit/save matrix checks partial
alpha, selection and channel protection, group defaults, KRA/PNG, further editing
and history. The renderer's resource tests cover allocation reuse, retained
pixels and retry after a capacity rejection. Run these contracts and compare the
fixed output artifacts on each supported environment before accepting new values.
